# Biostatistics Mastery — Android Application

Student-oriented offline biostatistics learning app for Zoology & Life Sciences.

## Features
- Full six-unit syllabus with biological examples
- Interactive Analysis Laboratory (t-test, Chi-square, ANOVA, correlation, etc.)
- Quizzes, flashcards, formula explorer
- Student Toolkit: mnemonics, worked examples, formula cheat-sheet
- English + Tamil support
- Custom science-themed icon
- Fully offline

## How to build
1. Open this folder in Android Studio (Hedgehog or newer recommended).
2. Let Gradle sync.
3. Build → Build Bundle(s) / APK(s) → Build APK(s).
4. Or run directly on a connected device/emulator.

## Package
`com.gasc.zoology.biostat`
